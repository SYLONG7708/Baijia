# 2026-07-11 方向塌縮修復稽核

## 問題

- 舊版以「含佣金後虧損較少的一側」充當「下一局最高機率方向」。例如莊機率 `50.61%` 時，畫面仍可能顯示閒 `49.39%`。
- 未通過樣本外驗證的線上集成會覆蓋五路投票，因此 12 組相反測試路型全部顯示閒。
- 平台缺少牌靴編號時，歷史資料按局號排序，會把不同日期、不同牌靴的同局號串成假時序。

## 修復

- `probabilityDirection` 只選擇機率至少 `50%` 的一側。
- `economicPreference` 獨立表示含 5% 莊佣金後 EV 較優側，不再冒充機率方向。
- AI 未通過樣本外驗證時，綜合方向使用五路、歷史與進階訊號投票；AI 機率另列對照。
- 沒有靴號時，依時間、局號重置與長時間間隔推斷牌靴邊界；同靴修正局只保留最新資料。

## 驗證結果

- 方向防塌縮：修復前 `莊 0 / 閒 12`；修復後 `莊 6 / 閒 6`。
- 36 桌回測：`1,970` 個非和局檢查全部完成，無失敗桌。
- 目前最佳點估計：`forcedEveryHandReverse` 命中 `51.32%`，Wilson 下限 `49.11%`。
- 平注 ROI：點估計 `+1.25%`，95% 下限 `-2.72%`，仍未證明正報酬。
- 線上集成：命中 `50.00%`，ROI `-2.26%`，Brier skill `-0.00002`。

因此正式品質閘門維持「未證明優勢」。本次修復解決方向與時序語義錯誤，不宣稱可以保證命中或獲利。
